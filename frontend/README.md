# 프론트엔드 UI

PHGC의 Wails v2 데스크톱 화면입니다. Vite와 Vanilla JavaScript, Tailwind CSS v4 기반으로 동작합니다.

## 구성

- `src/main.js`: 로그인, 대시보드, 상담·지원현황·원서대장·사용 설명서 화면과 Wails 바인딩
- `src/style.css`: 반응형 다크 테마와 A4 인쇄 스타일
- `wailsjs/`: Go 백엔드 메서드 바인딩
- `vite.config.js`: Vite 빌드 설정

## 현재 UI 원칙

- 학년부장·담임·진로부장 권한에 따라 쓰기 기능을 구분합니다.
- 담임 화면은 본인 학급만, 진로부장 화면은 전교 조회 전용으로 표시합니다.
- 1:1 프라이버시 상담, 화면 잠금, 모달 `ESC` 닫기, A4 인쇄/PDF를 제공합니다.
- 고교 상담은 일반계고 → 마이스터고 → 특성화고 순서로 판단하되, 실제 지원 현황은 전형 순서와 지원 제한을 별도로 검증합니다.
- 지원 현황에서 학교·전형을 선택하면 저장된 전형별 점수를 불러오고, 학과 1~5지망은 중복 선택을 막습니다.
- 인쇄 화면은 A4 세로·가로 용지에 맞게 별도 스타일을 적용하며 화면용 스크롤바·버튼은 인쇄에서 숨깁니다.

## 개발

```powershell
npm install
npm run dev
npm run build
```

전체 데스크톱 실행과 바인딩 갱신은 프로젝트 루트에서 `wails dev` 또는 `wails build`로 수행합니다.
