# 프론트엔드 UI (Frontend) — 그래서? 넌 어디 갈래?

이 디렉터리는 Wails v2 데스크톱 셸 위에서 구동되는 **"그래서? 넌 어디 갈래?"**의 사용자 인터페이스(UI) 소스코드입니다.

## 기술 스택

- **번들러/빌드 도구:** Vite
- **UI 스타일링:** Tailwind CSS v4 + 커스텀 글래스모피즘(Glassmorphism) 다크 테마
- **스크립트:** 모던 Vanilla JavaScript (SPA 단일 페이지 애플리케이션 구조)
- **차트/시각화:** Canvas 기반 성적 게이지, 최근 5개년/3개년/1년 합격선 탭별 비교 차트
- **데스크톱 브릿지:** Wails 런타임 양방향 바인딩 (`frontend/wailsjs/`)

## 프로젝트 구조

```text
frontend/
├── index.html          # 메인 데스크톱 애플리케이션 HTML 셸
├── src/
│   ├── main.js         # 전체 화면 렌더링, 100% 오프라인 사용동의서, 학년부장/담임 가이드, Wails 바인딩
│   ├── style.css       # Tailwind CSS v4 및 반응형 글래스모피즘 스타일
│   └── assets/         # 애플리케이션 이미지 및 로고 에셋
├── wailsjs/            # Go 백엔드 메서드 자동 생성 바인딩 인터페이스
├── package.json        # 프론트엔드 패키지 의존성 및 빌드 스크립트
└── vite.config.js      # Vite 빌드 설정
```

## 주요 화면 및 사용자 경험

1. **100% 오프라인 사용동의서 모달**:
   - 최초 실행 시 외부 전송 원천 차단, AES-256 로컬 암호화, 개인정보 보호 의무 조항에 대한 필수 동의 절차 수행.

2. **로그인 및 권한 관리**:
   - **`학년부장` (관리자 모드):** 나이스 엑셀 원본 연동, 학급별 배포 패키지(`.phgcpkg`) 생성, 담임 취합 패치(`.phgcpatch`) 안전 병합, 타교 자료 교환(`.phgcdata`). 상단 `[🛠️ 학년부장 관리 도구]` 전용 툴바 제공.
   - **`담임교사` (학급 모드):** 본인 담당 반 학생만 안전하게 열람, 1:1 고입 상담 및 지망 고교 입력, 변경분 취합 파일 내보내기.
   - **`진로부장 (조회전용)`:** 전교생 성적 및 지망 현황을 읽기 전용으로 안전하게 모니터링.

3. **고교별·전형별 1차 합격 예측 엔진**:
   - 후기 일반계고 (200점 만점: 교과 160 + 출결 16 + 봉사 8 + 행발 8 + 창체 8)
   - 마이스터고(울산마이스터고, 울산에너지고, 현대공업고) 일반/특별전형 가중치 산출
   - 관내 특성화고 일반/취업희망자 전형 실시간 점수 비교
   - 전기 기타고/특목고 지원 현황 및 메모 관리

4. **최근 5개년 커트라인 통합 분석**:
   - 최근 5개년(2027~2023) 합격선 탭별 즉시 전환 및 4단계 신호등(안정/적정/소신/위험) 합격 확률 진단.

5. **공식 배포자료실 연계 안내**:
   - 최신 버전 및 릴리즈 소식 확인 시 공식 배포자료실(`https://gguk.link/boards/phgc?category=%EB%B0%B0%ED%8F%AC%EC%9E%90%EB%A3%8C`)로 바로 연결.

## 로컬 개발 및 빌드

```bash
# 프론트엔드 의존성 설치
npm install

# Vite 개발 서버 단독 실행
npm run dev

# 프로덕션 빌드 검증
npm run build
```
*(Wails 데스크톱 실행 테스트는 프로젝트 루트에서 `wails dev`를 실행합니다.)*
