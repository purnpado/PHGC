# 프론트엔드 UI (Frontend)

이 디렉터리는 Wails v2 프레임워크와 결합하여 데스크톱 애플리케이션의 웹 인터페이스를 구동하는 프론트엔드 소스코드입니다.

## 기술 스택

- **번들러/빌드 툴:** Vite
- **UI 스타일링:** Tailwind CSS v4 + 커스텀 글래스모피즘(Glassmorphism) 다크 테마
- **스크립트:** 모던 Vanilla JavaScript (SPA 단일 페이지 애플리케이션 구조)
- **차트/시각화:** Canvas 기반 맞춤형 게이지 및 실시간 성적 분포 시각화
- **데스크톱 브릿지:** Wails 런타임 바인딩 (`frontend/wailsjs/`)

## 프로젝트 구조

```text
frontend/
├── index.html          # 메인 데스크톱 애플리케이션 HTML 셸
├── src/
│   ├── main.js         # 전체 화면 라우팅, 모달, 성적 계산 및 Wails 바인딩 처리 핵심 로직
│   └── style.css       # Tailwind CSS v4 설정 및 글래스모피즘, 애니메이션 커스텀 스타일
├── wailsjs/            # Go 백엔드 메서드 자동 생성 JS/TS 바인딩 인터페이스
├── package.json        # 프론트엔드 의존성 및 Vite 스크립트 정의
└── vite.config.js      # Vite 빌드 설정
```

## 주요 화면 및 사용자 권한 구조

1. **로그인 화면:**
   - **`학년부장` (관리자 마스터):** 나이스 엑셀 연동, 학교 설정, 비밀번호 변경, 커트라인 중앙 서버 등록/회수 등 시스템 전체 권한.
   - **`담임교사` (반별 모드):** 담당 반(1반, 2반...) 선택 후 해당 학급 학생들의 성적 단독 열람 및 1:1 고입 상담 진행.
   - **`진로부장 (조회전용)`:** 전체 학급의 성적 및 고교 진학 지망 현황을 조회 전용 모드로 안전하게 모니터링.

2. **나이스 엑셀 3단계 순서형 임포트 파이프라인:**
   - [1단계: 나이스 엑셀 파일 선택] ➡️ [2단계: 성적 데이터 분석 및 반별 DB 분할 저장] ➡️ [3단계: 학생 성적 조회 화면 바로가기]

3. **고교 전형별 맞춤 계산 및 합격 예측 엔진:**
   - 울산 관내 후기 일반고 (내신 200점 만점: 교과 160점 + 출석 16점 + 봉사 8점 + 행발 8점 + 창체 8점)
   - 울산마이스터고 (내신 + 출결/봉사 가중치 및 교과 전형식)
   - 현대공고, 에너지고, 애니원고, 예술고, 스포츠고 등 학교별/전형별 세부 전형요강 알고리즘 실시간 반영

4. **원클릭 자동 업데이트 UI:**
   - 앱 실행 시 백그라운드에서 신규 버전을 자동 감지하고 모달 안내 제공.
   - [지금 즉시 자동 업데이트 및 재시작] 클릭 시 다운로드 게이지 표시 후 무중단 재실행.

## 로컬 개발 방법

```bash
# 프론트엔드 의존성 설치
npm install

# Vite 개발 서버 단독 실행
npm run dev

# 빌드 검증
npm run build
```
*(실제 Wails 데스크톱 바인딩 연동 테스트는 프로젝트 루트에서 `wails dev`를 사용합니다.)*
