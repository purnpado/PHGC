# PHGC v1.6.0 릴리즈 노트

v1.5.2 이후의 기능 추가와 안정화 내용입니다.

## 진학 산출·상담

- 후기 일반계고, 울산마이스터고, 울산에너지고, 현대공업고 및 관내 특성화고의 전형별 1차 점수 산출을 정비했습니다.
- 울산에너지고의 학기별 성취비율·반올림·학기 성적 합산을 공식 요강과 엑셀 산출식에 맞게 보완했습니다.
- 학생별 고교·전형 점수를 저장해 지원 현황 입력 시 점수 스냅샷으로 즉시 불러오도록 개선했습니다.
- 지원 학교 선택에 따라 전형 유형과 학과 지망을 자동 구성하고, 1~5지망 학과 중복을 막았습니다.
- 고교별 점수 상세 명세를 상담 화면에서 확인할 수 있게 했습니다.

## 커트라인·공개자료

- 연도별 커트라인을 최근 1·3·5개년 기준으로 관리하고, 연도 전환·복사·학교명·학과·전형 정규화를 보완했습니다.
- 고교 공식·교육청 공개자료와 학교 입력 자료의 관리 기준을 분리했습니다.
- 타학교 자료 병합 때 고교명·학과·전형 표기 차이로 중복되는 문제를 개선했습니다.

## 학교 운영·보안

- 학년부장 배포자료(`.phgcpkg`), 담임 변경분(`.phgcpatch`), 비밀번호 재설정(`.phgcreset`) 흐름을 안정화했습니다.
- 배포자료 재적용 때 담임의 상담 이력·희망학교·메모를 병합해 보존하도록 보완했습니다.
- 화면 잠금과 자동 잠금, 역할별 권한을 정비했습니다.

## 화면·출력

- 진학상담 대시보드의 관심학교, 지원·합격 현황, 통계와 원서대장 UI를 개선했습니다.
- 개인 상담표·종합성적표·신호등 매트릭스의 A4 인쇄 레이아웃과 색상·표·그래프 출력을 보완했습니다.
- 상담 모달의 고정 헤더, ESC 닫기, 서명 푸터, 전역 접근성·스타일 경고를 정리했습니다.

## 확인 사항

- 본 버전의 예측 결과는 상담 보조용입니다. 실제 원서 접수 전에는 해당 고교의 당해 연도 공식 산출표와 표본 학생을 대조하십시오.
- 학교별 개인정보와 상담 자료는 중앙 서버나 릴리즈에 포함되지 않습니다.
