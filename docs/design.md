# 너~어디갈래? — 종합 설계 문서 (Design Document)

> **프로그램 정식 명칭:** 그래서? 넌 어디갈래?
> **버전:** v0.2.0 (통합 산출 엔진 적용)
> **최종 수정:** 2026-09-03

---

## 1. 프로그램 목적

3학년 1학기 성적이 나온 시점(9월)에서, 담임 선생님이 학생 개개인의 마이스터고/특성화고 내신 점수를 즉시 산출하여 진학 상담에 활용한다.
일반고 상담은 교육청 프로그램이 있으므로, 본 프로그램에서는 참고 지표(신호등)만 제공한다.

## 3. 나이스 과목 분류 체계

나이스 엑셀에서 "교과"는 **교과군**(예: 국어, 수학, 사회, 과학, 체육 등)이고, "과목"이 **실제 교과목**(예: 국어, 영어, 수학, 기술·가정 등)이다.

### 가중치 과목 매칭 규칙 (중학교 기준)
- **영어:** 과목명에 "영어"가 포함되면 영어 과목 (영어, 영어회화 등 → 한 학기에 하나만 수강)
- **수학:** 과목명에 "수학"이 포함되면 수학 과목
- **기술가정:** 과목명에 "기술" 또는 "가정"이 포함되면 기술가정 과목

### 공통 사항
- 성취도 환산: A=5, B=4, C=3, D=2, E=1, P=제외(자유학기)

- 소수점: 셋째 자리에서 반올림하여 둘째 자리까지

### 후기 일반고 (울산광역시교육청 전형요강 200점 만점 기준)
- **총점:** 200점 만점 (교과 80% 160점 + 비교과 20% 40점)
- **교과성적 (160점):** `160 - (0.96 × 석차백분율)`, 소수 셋째 자리에서 반올림
  - 석차백분율: `개인 석차 ÷ 학년 재적수 × 100`
  - 교과점수 총점(5학기): `S11 + S12 + S13 + S21 + S22`
  - S11: 1학년 자유학기가 아닌 학기 평균 × 5.44
  - S12/S13: 2학년 1·2학기 평균 × 각 5.44
  - S21/S22: 3학년 1·2학기 평균 × 각 7.84
- **비교과성적 (40점):**
  - **출석성적 (16점):** `4 + 학년별 출석점수 3개`. 미인정 결석·지각·조퇴·결과만 반영하며, 지각/조퇴/결과는 3회당 결석 1일(2회 이하는 버림)로 환산한다. 학년별 0일=4.0점, 1일=3.5점, …, 7일=0.5점, 8일 이상=0점이다.
  - **봉사활동 (8점):** `2 + 학년별 봉사점수 3개`. 4시간 이상=2.0점, 3시간=1.7점, 2시간=1.4점, 1시간=1.0점, 1시간 미만=0점이다. 2020~2021학년도 재학 학년은 예외로 2점을 부여한다.
  - **행동발달 (8점):** `5 + 학년별 인성 관련 학교장 표창 가산점 1점씩`(최대 3점). 해당 학년 학교폭력·징계·교권보호 조치자는 제외한다.
  - **창체활동 (8점):** `5 + 학년별 학생자치회·학급 임원·동아리 반장 가산점 1점씩`(최대 3점). 해당 학년 학교폭력·징계·교권보호 조치자는 제외한다.
- **지원 가이드 판정:** 교과 백분율 80% 이내 🟢(합격 안정) / 80~90% 🟡(경계선) / 90% 초과 🔴(지원 주의) 신호등 제공

## 5. 화면 설계

### 5-1. 담임 대시보드 (메인 표)
**개인정보 보호:** 학생 이름만 표시하고, 점수는 숨김 처리.
- 번호 | 성명 | [상세보기 버튼]
- 학생 이름 또는 버튼 클릭 시 → 진학상담 모달 팝업

### 5-2. 진학상담 모달 (학생 클릭 시)
학생 한 명의 전체 성적과 **모든 학교의 합격 가능성**이 한 화면에 표시됨.
- 교과 성적 요약 (전과목 평균, 가중치 과목별 점수)
- 비교과 요약 (출결, 봉사)
- 수기 입력 영역 (추가 봉사시간, 창체/행발 학년별 체크박스)
- 학교별 합격 가능성 게이지바 (커트라인 데이터 기반)
- 일반고 가능성 신호등
- [인쇄/PDF] 버튼

### 5-3. 반 전체 요약 (별도 페이지 - 신호등 매트릭스)
```

김민준 |    🟢     |   🟢    |   🟡    |  🟢   |  🟢
이서준 |    🟡     |   🟢    |   🟢    |  🟢   |  🟡
```

### 5-4. 데이터 업데이트 시점 표시
관리자 대시보드 및 담임 화면 상단에:
`교과: 2026.09.01 ✅ | 출결: 2026.09.02 ✅ | 봉사: 미업로드 ⚠️`

## 6. 데이터 생명주기

### 입시년도 전환 시 자동 파기
- **보존:** 학교별·학과별 커트라인 최저치 점수 (크라우드소싱 데이터)
- **삭제:** 학생 교과성적, 출결, 봉사, 수기입력 가산점 등 모든 개인정보
- 관리자에게 "새 학년도로 전환하시겠습니까?" 확인 후 실행

### 브릿지 서버 전송 데이터
- **전송 O:** 고등학교명, 학과명, 전형, 합격 최저점수
- **전송 X:** 학생 이름, 번호, 성적 등 개인정보 일체

### 교내 오프라인 협업과 재취합

학교 자료는 네트워크 공유를 전제하지 않는다. 학년부장은 나이스 자료를 처리한 원본을 담임·진로부장에게 배포하고, 담임은 **자기 반만** 출결·봉사·창체·행발·수기 가산점을 입력한다.

담임은 전체 `data` 폴더를 다시 보내지 않고, `변경분 내보내기`로 만든 암호화된 `.phgcpatch` 파일만 학년부장에게 전달한다. 변경분에는 기준 배포본 버전, 학급, 변경 학생 식별값, 허용된 입력 필드와 변경 시각만 포함한다. 학년부장은 `변경분 가져오기`로 이를 검토·병합하고 최신 `data` 폴더를 재배포한다.

- 담임은 다른 학급의 변경분을 만들거나 병합할 수 없다.
- 진로부장은 조회 전용이다.
- 기준 배포본 버전이 다르거나 동일 학생·필드가 이미 변경된 경우 자동 덮어쓰지 않고 학년부장에게 충돌 목록을 보여준다.
- 변경분 파일과 `data` 폴더는 특정 기기·Windows 계정에 묶이지 않는 공용 데이터 잠금 비밀번호 기반 AES-256-GCM으로 암호화한다.

## 7. 배포 및 자동 업데이트

### 실행 방식 (두 가지 모두 지원)
1. **공유폴더 방식:** 학교 서버의 공유 폴더에 exe를 두고, 각 PC에서 직접 실행
2. **개별 배포 방식:** 메신저 등으로 exe를 전달받아 개인 PC에서 실행

### 자동 업데이트
- 프로그램 시작 시 Gitea Release에서 최신 버전 확인
- 새 버전이 있으면 다운로드 링크 안내 (현재)
- 향후: 자동 다운로드 및 교체 (업데이터 프로그램 별도 구현)
