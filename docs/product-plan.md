# PHGC 운영 기획 기준

학교별 1차 전형 산출식의 공식 근거·검증 상태는 [고입 1차 전형 산출식 전수 점검 기획안](admission-score-audit-plan.md)에서 별도로 관리한다.

이 문서는 PHGC의 기능 구현과 보안 판단을 위한 기준 문서다. 소스 저장소에서만 버전 관리하며, Gitea Release Asset·프로그램 배포 폴더·학교별 `data` 폴더에는 포함하지 않는다.

## 운영 흐름

1. 학년부장이 프로그램을 내려받아 중학교명, 3학년 학급 수, 관리자 비밀번호를 설정한다.
2. 학년부장이 나이스에서 내려받은 성적 자료를 프로그램으로 처리한다.
3. 학년부장이 원서대장을 근거로 고등학교 커트라인을 직접 입력한다.
4. 학년부장이 사용자 권한 관리에서 담임교사와 진로부장의 초기 비밀번호를 설정한다.
5. 프로그램과 학교별 `data` 폴더를 담임교사·진로부장에게 전달한다.
6. 담임은 자기 반의 9/30 출결·봉사, 창체·행발, 수기 가산점을 입력하고 암호화된 변경분 파일만 학년부장에게 전달한다.
7. 학년부장은 변경분을 검토·병합한 뒤 최신 상담 자료를 재배포한다.
8. 교사는 초기 비밀번호로 로그인한 뒤 개인 비밀번호를 설정하고, 자신의 역할에 따라 진학상담에 사용한다.

담임교사 자료를 중앙 서버로 자동 수집하지 않는다. 교내 재취합이 필요할 때는 전체 DB가 아닌 학급별 암호화 변경분 파일을 학년부장에게 전달한다.

## 역할

- 학년부장: 초기 설정, 나이스 자료 처리, 사용자 관리, 커트라인 입력과 배포를 관리한다.
- 담임교사: 담당 학급 학생의 진학상담에 활용한다.
- 진로부장: 전체 학급을 조회하며 진학상담을 지원한다.

## 개인정보와 데이터 보안

- 학생 성적·출결·봉사·행동특성 등 나이스 자료는 학교의 로컬 `data` 폴더에서만 다룬다.
- 외부 서버는 나이스 자료를 자동 수집하거나 저장하지 않는다.
- `data` 폴더의 DB는 이동식 저장장치와 클라우드 전달을 고려해, 특정 PC나 Windows 계정에 묶이지 않는 암호화 방식을 사용한다.
- DB 암호화는 학년부장이 설정한 공용 데이터 잠금 비밀번호를 기반으로 한다. 담임·진로부장은 전달받은 암호로 DB를 연 뒤, 자신의 개별 사용자 계정으로 로그인한다.
- 기기·Windows 계정 종속 방식(DPAPI)은 사용하지 않는다.
- 담임 변경분은 기준 배포본 버전과 학급 정보를 포함하며, 충돌은 학년부장이 검토한 뒤 병합한다.

### 배포와 잠금 해제 흐름

1. 학년부장에게는 `PHGC.exe`만 전달한다.
2. 학년부장이 최초 실행해 `data` 폴더를 만들고, 기초 설정·나이스 자료·커트라인·교사 초기 계정을 준비한다.
3. 학년부장은 실행파일과 암호화된 `data` 폴더를 ZIP으로 묶어 담임·진로부장에게 전달한다.
4. 교사는 최초 한 번 공용 데이터 암호와 본인 초기 계정 비밀번호를 입력한 뒤 개인 비밀번호를 설정한다.
5. 이후 실행은 개인 비밀번호 한 번만으로 데이터 잠금 해제와 역할 로그인을 수행한다.

공용 데이터 암호는 최초 배포본을 여는 데만 사용한다. 이후의 사용자별 잠금 해제 정보는 해당 사용자의 개인 비밀번호로 AES-256-GCM 암호화해 `data` 폴더에 보관한다. 이 정보는 Windows 계정이나 특정 기기에 종속되지 않는다.

## 중앙 서버와 공개 커트라인

중앙 서버는 공개 커트라인 자료와 프로그램 업데이트의 배포 허브다. 커트라인 제출은 사용자가 명시적으로 실행할 때만 수행한다.

제출·승인·공개에 허용되는 커트라인 데이터는 아래 항목으로 한정한다.

```json
{
  "admissionYear": 2026,
  "sourceMiddleSchoolName": "제출 중학교명",
  "targetHighSchoolName": "대상 고등학교명",
  "department": "학과명 또는 빈 값(전체)",
  "cutoffScore": 172.4
}
```

학생·학급·교사·성적 원본·출결·봉사 데이터는 중앙 서버로 전송하거나 저장하지 않는다. 제출 자료는 운영자 승인 전까지 공개하지 않는다.

## 배포 원칙

- Gitea 소스 저장소에는 코드와 이 기획 문서를 보관한다.
- Gitea Release Asset에는 `PHGC.exe`만 첨부한다.
- 기획 문서, 소스코드, 토큰, 환경설정, 학생 자료, 학교별 `data` 폴더는 Release Asset에 포함하지 않는다.
