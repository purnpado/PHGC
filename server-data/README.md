# PHGC 기준 데이터

`server-data`는 프로그램 배포 시 함께 제공하는 **개인정보 없는 기준 데이터** 폴더입니다.

```text
server-data/
├── version.json        # 최신 버전·릴리즈 안내 주소
├── highschools.json    # 고등학교·학과·계열 마스터 목록
└── cutoffs/            # 연도별 고교·학과·전형별 커트라인 기준
```

## 데이터 사용 원칙

1. **고교 공식·교육청 공개자료**: 운영자가 확인한 공개 자료만 기준값으로 반영합니다. 학교 사용자는 이를 편집하지 않습니다.
2. **학교 입력 자료**: 각 중학교는 원서대장·상담 결과로 확인한 합격선 자료를 자체 `data` 폴더에 관리합니다.
3. **중앙 취합 자료**: 참여학교가 개인정보 없이 제출한 확정 커트라인만 활용합니다.

커트라인은 중학교명, 입학년도, 고등학교명, 학과(또는 전체), 전형, 합격자 최저점·최고 불합격점·평균점 등 진학 분석에 필요한 최소 정보만 다룹니다. 학생·학급·교사·상담 정보는 포함하지 않습니다.

## 주의

- JSON은 BOM 없는 UTF-8로 저장합니다.
- `data/`, `*.db`, 나이스 엑셀, 암호화 배포·취합 파일은 이 폴더나 릴리즈에 넣지 않습니다.
- `PHGC.exe`는 공식 릴리즈 에셋으로 배포하며 이 폴더에서 버전 관리하지 않습니다.
