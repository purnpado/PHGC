# 그래서? 넌 어디 갈래? (PHGC)

울산 관내 중학교 3학년의 고입 진학지도를 위한 **오프라인 데스크톱 프로그램**입니다. 나이스(NEIS) 엑셀 자료를 학교 PC에서만 처리하고, 학교별 고입 산출식·커트라인·실제 지원 결과를 바탕으로 담임과 진로교사가 상담할 수 있게 돕습니다.

## v1.6.0 핵심 원칙

- 학생 개인정보, 성적, 상담 이력, 지원·합격 결과는 중앙 서버로 전송하지 않습니다.
- `data` 폴더의 학교 자료와 교사용 교환 파일은 사용자가 정한 **공용 데이터 암호 기반 AES-256-GCM**으로 보호합니다. 특정 PC나 Windows 계정에 묶이는 DPAPI는 사용하지 않습니다.
- 고교 공식·교육청 공개자료, 학교가 입력한 자료, 참여학교에서 개인정보 없이 취합한 자료를 구분해 상담에 활용합니다.
- 모든 산출·예측은 상담 보조 자료입니다. 원서 접수 전에는 해당 고교의 당해 연도 공식 요강·산출표와 반드시 표본 대조해야 합니다.

## 역할과 권한

| 역할 | 할 수 있는 일 |
| --- | --- |
| 학년부장 | 학교 기초 설정, 나이스 자료 입력, 계정·공용 암호 관리, 공식 공개자료·커트라인 관리, 담임 배포자료 생성, 변경분 병합, 전교 현황·보고서 출력 |
| 담임 | 본인 학급 조회, 1:1 상담, 비교과·상담 메모·지원/합격 현황 입력, 학급 변경분 내보내기 |
| 진로부장 | 전교 학생 및 현황 조회·상담 지원(읽기 전용) |

## 학교 운영 흐름

### 1. 학년부장 최초 준비

1. 새 폴더에 `PHGC.exe`를 놓고 실행합니다.
2. 학교명, 학급 수, 고교 입학년도, 학년부장 비밀번호와 공용 데이터 암호를 설정합니다. 실행 위치에 `data` 폴더가 생성됩니다.
3. 나이스 교과성적·출결·봉사 엑셀을 불러오고, 표본 학생으로 공식 산출값과 대조합니다.
4. 고교별 공식 공개자료와 학교 원서대장 기반 커트라인을 입력합니다.
5. 사용자 및 권한 관리에서 `301`, `302` 등 담임 계정과 `jinro` 계정을 준비합니다.

### 2. 담임에게 전달

학년부장은 각 계정의 **배포 자료 만들기**로 `.phgcpkg` 파일을 생성해 다음 세 가지를 함께 전달합니다.

- `PHGC.exe`
- 해당 담임용 `.phgcpkg` 배포 자료
- 공용 데이터 암호와 초기 비밀번호(별도 안전한 방법으로 전달)

담임은 **새 프로그램 폴더**에서 `PHGC.exe`를 실행하고, 로그인 화면의 **학년부장 배포 자료 가져오기**를 선택합니다. 배포 자료 적용 뒤 공용 데이터 암호와 초기 비밀번호로 로그인한 다음, 본인 비밀번호로 변경합니다.

> 기존 `data` 폴더가 이미 있는 경우에는 같은 폴더에 새 배포 자료를 덮어쓰지 마십시오. 새 폴더에서 적용하거나 기존 자료를 먼저 백업하십시오.

### 3. 학기 중 상담과 취합

- 담임은 1:1 프라이버시 상담, 비교과 보정, 지원·합격 현황, 상담 메모를 입력합니다.
- 지원 현황은 학교 내부 암호화 DB와 `.phgcpatch` 취합 파일에만 저장됩니다.
- 담임은 **취합자료 제출**로 `.phgcpatch`를 학년부장에게 전달합니다.
- 학년부장은 **취합자료 병합**에서 여러 반 파일을 검토·병합한 뒤, 최신 배포 자료를 다시 만들 수 있습니다.
- 비밀번호를 잊은 담임에게는 학년부장이 재설정 파일(`.phgcreset`)을 발급합니다. 학급 DB 파일만 따로 보내는 방식은 사용하지 마십시오.

## 주요 기능

- 나이스 교과·출결·봉사 엑셀 연동 및 전교 석차 스냅샷 배포
- 후기 일반계고, 울산마이스터고·울산에너지고·현대공업고, 관내 특성화고의 전형별 1차 점수 산출
- 3학년 1학기 기준의 예상 산출과 전형별 마감일(마이스터 9/30, 특성화 취업 9/30·일반 10/31, 후기 일반고 11/30) 안내
- 공식 공개자료·학교 입력자료·누적 커트라인의 연도별 관리 및 최근 1·3·5개년 비교
- 학생별 1~5지망 학과, 지원 전형, 지원 상태, 최종 배정 학과, 점수 스냅샷 기록
- 담임·학년부장용 지원 현황, 고입원서대장, 학교별 결과 보고서, 신호등 매트릭스
- A4 인쇄/PDF: 개인 상담표, 종합성적표, 원서대장, 신호등 매트릭스
- `Ctrl+L` 화면 잠금, 자동 잠금, 비밀번호 재설정, AES-GCM 암호화 교환 파일

## 지원·합격 현황 입력 기준

- 마이스터고·특성화고는 학교와 전형을 선택하면 해당 학생의 저장된 학교별 전형 점수를 점수 스냅샷에 자동 기록합니다.
- 학과 지망은 선택한 학교의 학과 수만큼 표시되며, 앞 지망에서 선택한 학과는 다음 지망에서 제외됩니다.
- 후기 일반계고는 고교 배정 전형 특성상 지원점수 중심으로 기록합니다.
- 자사고·외고는 일반계고보다 앞선 전형으로 기록하며, 불합격 또는 포기일 때만 일반계고 지원 가능 여부를 판단합니다.
- 과학고·타시도 등 프로그램 분석 대상이 아닌 전형은 `기타`로 기록하고 점수 집계에서 제외합니다.

## 기준 데이터와 배포

- `server-data/highschools.json`: 고교·학과 기준 목록
- `server-data/cutoffs/`: 개인정보 없는 연도별 커트라인 기준
- `server-data/version.json`: 최신 버전 안내와 공식 다운로드 주소
- 공식 배포 파일: [GitHub Releases](https://github.com/purnpado/PHGC/releases)
- 소스 백업: [Gitea PHGC-OFFLINE](https://gitea.gguk.link/purnpadosori/PHGC-OFFLINE)

`data/`, 나이스 원본, `*.db`, `*.phgcpkg`, `*.phgcpatch`, `*.phgcreset`은 학교 운영 자료이므로 저장소와 릴리즈에 올리지 않습니다.

## 개발·빌드

```powershell
# 개발 실행
wails dev

# 배포용 실행 파일 빌드
wails build -trimpath -ldflags "-s -w"

# 릴리즈 파이프라인(버전·노트는 매 릴리즈마다 명시)
.\publish.ps1 -Version "1.6.0" -Notes "릴리즈 노트"
```

빌드 결과는 `build/bin/PHGC.exe`입니다.

## 책임 고지

프로그램의 산출값·커트라인·합격 예측은 진학상담 보조용입니다. 실제 전형 결과는 경쟁률, 면접·실기, 당해 연도 요강 등에 따라 달라질 수 있으므로 최종 원서 업무는 공식 전형요강과 학교의 검증 절차에 따라 처리해야 합니다.
