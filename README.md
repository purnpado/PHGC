# 그래서? 넌 어디 갈래? (PHGC)

**울산 관내 중학교 3학년 고입 모의지원 및 1:1 맞춤형 진학상담 소프트웨어**

> 본 프로그램은 외부 클라우드나 외부 서버로 학생 개인정보를 단 1바이트도 전송하지 않는 **100% 오프라인 독립형(Standalone) 데스크톱 프로그램**입니다. 나이스(NEIS) 원본 엑셀 자료를 로컬 PC 내부에서 안전하게 분석하고, 고교별 맞춤 산출 엔진과 최근 5개년 합격선 데이터를 바탕으로 학생의 합격 가능성을 즉시 진단합니다.

---

## 🔒 100% 오프라인 보안 및 암호화 아키텍처

- **외부 전송 원천 차단**: 서버 통신 및 외부 네트워크 요청이 전혀 없는 독립 폐쇄망 구조로 설계되어 개인정보 유출을 원천적으로 차단합니다.
- **AES-256-GCM 로컬 강력 암호화**: 학교별로 설정한 [공용 데이터 암호]를 기반으로 군사 표준 수준의 AES-256-GCM 알고리즘을 적용하여 학급 배포 파일(`.phgcpkg`) 및 담임 취합 파일(`.phgcpatch`), 타교 교환 자료(`.phgcdata`)를 안전하게 보호합니다.
- **실행 경로 독립성 보장**: 프로그램 바로가기나 상대경로 실행 시에도 오류가 발생하지 않도록 `os.Executable()`을 통해 실행 파일(`.exe`)의 절대 경로를 기준으로 DB와 에셋을 안정적으로 자동 생성·관리합니다.
- **한글 및 공백 경로 완벽 지원**: 학교 현장의 한글 폴더명 및 공백이 포함된 파일 경로(예: `C:\2027학년도 3학년 진학상담\`)에서도 문제없이 구동되도록 UTF-8 경로 결합을 처리합니다.

## 📋 핵심 주요 기능

1. **나이스(NEIS) 엑셀 자동 연동**:
   - 성적·출결·봉사 엑셀 파일을 원클릭으로 파싱하여 학급별/학생별 데이터 자동 구축.
   - 주민등록번호 뒷자리 등 불필요한 민감 정보는 메모리 적재 단계에서 즉시 마스킹/제외.

2. **고교별·전형별 1차 맞춤형 성적 산출 엔진**:
   - **후기 일반계고**: 울산 내신 200점 만점 및 학년별/영역별 석차백분율(%) 정밀 산출.
   - **마이스터고**: 울산마이스터고, 울산에너지고, 현대공업고 일반/특별전형별 가중치 산출.
   - **특성화고**: 관내 특성화고 일반전형 및 취업희망자 특별전형 1차 점수 실시간 비교.
   - **전기 기타고/특목고/자사고**: 과고, 외고, 예술고, 스포츠고, 애니원고, 고운고 등의 지원 이력 및 메모 관리.

3. **최근 5개년 합격선(커트라인) 통합 관리**:
   - 최근 5개년(2027~2023) 커트라인 데이터를 탭별로 한눈에 비교·분석.
   - 학교별/전형별 최저합격선 및 최고불합격선 기반 합격 가능성 4단계 신호등(안정/적정/소신/위험) 제공.
   - 인근 중학교와의 교환을 위한 관내 진학자료 내보내기/가져오기(`.phgcdata`) 및 비밀번호 보호 병합 지원.

4. **교내 안전 분할 배포 및 취합 워크플로우**:
   - **학년부장**: 나이스 자료 구축 후 반별 배포 파일(`.phgcpkg`) 생성 ➡️ 담임교사에게 전달.
   - **담임교사**: 자기 반 데이터만 암호화 열람 ➡️ 1:1 고입 상담 및 지망 고교 입력 ➡️ 변경분 패치 파일(`.phgcpatch`) 생성 ➡️ 학년부장에게 제출.
   - **학년부장 취합**: 담임교사들의 패치 파일을 선택적으로 확인 및 무결성 검증 후 최종 본교 DB에 원클릭 병합.

5. **학교 원서대장 및 지원현황 통계**:
   - 전기/후기 전형별 접수 대장 자동 생성, 입시 결과 확정 및 커트라인 피드백 반영.

## 🛠️ 작업 수칙 (개발 및 운영 지침)

본 프로젝트는 현직 교사의 직관적이고 안전한 활용을 위해 다음 작업 수칙을 절대적으로 준수합니다.

1. **100% 한국어 소통 및 커밋 (필수 준수)**:
   - 모든 사용자 대답, 코드 주석, 시스템 안내 문구, Git 커밋(Commit) 메시지는 예외 없이 **100% 한국어(Korean)**로만 작성합니다. 영문 커밋 메시지는 절대 사용하지 않습니다.
2. **실행 파일 절대경로 기반 동작**:
   - DB 파일(`phgc_master.db`) 및 로컬 자산은 `os.Executable()`로 획득한 실행 파일 위치를 기준으로 생성하여, 상대경로 실행에 따른 데이터 유실이나 미연결 오류를 원천 차단합니다.
3. **로컬 DB 및 보안 데이터 격리**:
   - `.gitignore`에 `*.db`, `*.sqlite`를 철저히 등록하여 학생 개인정보 및 로컬 DB 파일이 원격 저장소에 절대 업로드되지 않도록 보장합니다.
4. **저장소 분리 및 역할 준수**:
   - **Gitea (`PHGC-OFFLINE`)**: 내부 개발 소스 버전 관리 및 릴리즈 바이너리 업로드(사용자 승인 시).
   - **GitHub (`PHGC`)**: 순수 원본 소스 보관 전용 저장소 (릴리즈 바이너리 업로드 절대 금지).
   - **공식 배포자료실**: 사용자 배포 및 업데이트 패키지는 공식 웹 게시판 안내 링크(`https://gguk.link/boards/phgc?category=%EB%B0%B0%ED%8F%AC%EC%9E%90%EB%A3%8C`)를 통해 제공.

```text
PHGC/

│   └── windows/icon.ico              # Windows .exe 실행파일 및 작업표시줄 아이콘

```

## 🚀 빌드 및 실행 방법

### 개발 환경 실행
```powershell
wails dev
```

### 배포용 단일 실행 파일(.exe) 빌드
```powershell
wails build
```
빌드 완료 시 `build/bin/PHGC.exe`가 생성됩니다.

### 버전 릴리즈 배포
```powershell
# GitHub & Gitea 소스 동기화 및 릴리즈 빌드
.\publish.ps1 -Notes "최신 기능 업데이트 및 버그 수정"

# Gitea에만 선택적으로 릴리즈 실행파일 업로드 시
.\publish.ps1 -Notes "정식 배포" -UploadGiteaRelease
```
