# PHGC (고입 내신 산출 및 합격 예측 시스템)

> **울산 관내 중학교의 2026학년도 고등학교 입시 내신 산출 및 합격 예측을 돕는 경량·독립형 데스크톱 솔루션**

PHGC(PurnPadoSori Highschool Guidance Calculator)는 교내에서 나이스(NEIS) 성적 엑셀 데이터를 안전하게 분할 관리하고, 고등학교 전형별(전기 마이스터고·특성화고·예술고·체육고·외고 및 후기 일반고) 복잡한 내신 산출 공식에 맞춰 학생별 합격 가능성을 실시간 예측·상담할 수 있도록 지원하는 프로그램입니다.

---

## 👥 3계층 사용자 권한 체계

현장 중학교의 실제 교무 업무 분장에 최적화된 3단계 접근 모드를 제공합니다:

1. **학년부장 (관리자 마스터 모드)**
   - 초기 마스터 비밀번호 설정 및 교내 보안 인증
   - 나이스(NEIS) 3학년 종합 성적 엑셀 파일 Import 및 반별 DB 자동 분할 생성
   - 관내 고교별 합격 커트라인 등록, 취합 조회 및 회수(롤백/초기화)
   - 프로그램 최신 버전 배포 및 환경 설정 관리
2. **담임교사 (학급 전담 상담 모드)**
   - 담당 반(1반, 2반...) 단독 선택 및 해당 학급 학생 명단 자동 로드
   - 학생별 1~3학년 교과 성적 및 비교과(출결, 봉사, 행동특성) 시각적 게이지 분석
   - 지망 고교/학과 선택 시 실시간 가산점 및 가중치 반영 내신 산출 및 합격 가능성 진단
3. **진로부장 (조회전용 모드)**
   - 3학년 전체 학급의 성적 현황 및 고교별 진학 희망 분포를 조회 전용으로 안전하게 모니터링
   - 데이터 위변조 위험 없이 교내 전체 진학 통계 확인 및 고입 상담 지원

## ✨ 핵심 기능

- **📊 나이스(NEIS) 성적 엑셀 3단계 원클릭 파이프라인**
  - 복잡한 성적표를 클릭 세 번으로 분석: `[1단계: 파일 선택]` ➡️ `[2단계: 성적 자동 분석 및 반별 DB 분할]` ➡️ `[3단계: 조회 화면 이동]`
  - 성취평가제(A/B/C/D/E), 체육·음악·미술 과목군 자동 구분 및 결측치 완벽 보정
- **🎯 울산 관내 고교 전형별 맞춤형 내신 산출 엔진**
  - **후기 일반계고:** 울산광역시 교육청 고입전형요강 기준 **내신 200점 만점** 표준 산출
    - **교과 성적 (80%, 160점):** 1·2학년 40.8%(81.6점) + 3학년 39.2%(78.4점)
    - **비교과 성적 (20%, 40점):** 출석 8%(16점) + 봉사활동 4%(8점) + 행동발달상황 4%(8점) + 창의적체험활동 4%(8점)
  - **전기 마이스터고:** 울산마이스터고(200점), 현대공고(300점), 울산에너지고(200점) 등 학교별 전형요강 가중치 공식 정밀 계산
  - **특성화고 / 특목·예체능고:** 울산애니원고, 울산예술고, 울산스포츠고, 울산외고 등 전형별 교과/출결/봉사/면접 배점 기준 적용
- **🌐 비공개 중앙 프록시 서버 연동 (`go.gguk.link`)**
  - 비공개(Private) 저장소의 관리자 토큰을 프로그램 내에 노출하지 않는 안전한 프록시 아키텍처
  - 관내 중학교들이 등록한 최신 합격 커트라인 실시간 일괄 취합 및 자동 동기화
- **🚀 무중단 원클릭 자동 업데이트 시스템**
  - 프로그램 실행 시 백그라운드에서 신규 버전을 자동 감지
  - 업데이트 클릭 시 최신 바이너리 백그라운드 다운로드 후 프로세스 자동 교체 및 재시작
  - 한글 폴더명 및 다국어 경로 환경에서도 결함 없이 작동하는 순수 ASCII 상대경로 스크립트 엔진 내장
- **💬 교사 피드백 및 문의 창구 내장**
  - 사용 중 개선 건의사항이나 오류 발생 시 화면 캡처 첨부와 함께 즉시 접수 (Gitea Issue 자동 등록 및 관리자 알림)

## 🛠️ 기술 스택

| 영역 | 사용 기술 | 설명 |
| :--- | :--- | :--- |
| **데스크톱 프레임워크** | **Wails v2** | Go 백엔드와 웹 프론트엔드를 네이티브 WebView2로 바인딩하는 고성능 프레임워크 |
| **백엔드 언어** | **Go (Golang 1.23+)** | 빠르고 가벼운 단독 실행 파일 컴파일, 동시성 처리 및 네트워크 통신 |
| **데이터베이스** | **SQLite (`modernc.org/sqlite`)** | CGO 의존성 없는 100% 순수 Go 임베디드 데이터베이스 |
| **프론트엔드 UI** | **Vanilla JS + Vite** | 군더더기 없는 초경량 SPA 아키텍처 및 반응형 상태 관리 |
| **스타일링** | **Tailwind CSS v4** | 최신 글래스모피즘(Glassmorphism) 다크 테마 및 부드러운 애니메이션 |
| **인프라 / 배포** | **Gitea + Go Gin Proxy** | 비공개 코드 저장소, 릴리즈 바이너리 저장소 및 보안 브릿지 프록시 |

## 📁 디렉토리 구조

```text
PHGC/
├── app.go                  # Wails 애플리케이션 라이프사이클 및 프론트엔드 바인딩 API
├── calc.go                 # 일반계고 기본 내신 및 과목별 환산점수 계산 엔진
├── calc_school.go          # 마이스터고/특성화고/예술고/스포츠고 등 학교별 전형 계산 엔진
├── db.go                   # SQLite 데이터베이스 생성, 설정 및 학생 성적 CRUD
├── parser.go               # 나이스 성적 엑셀 파일 파서 (교과 성적)
├── parser_nonsubject.go    # 나이스 비교과(출결, 봉사, 행동특성) 파서
├── sync.go                 # 중앙 프록시 서버 연동 및 데이터/버전 동기화 매니저
├── updater.go              # 백그라운드 다운로드 및 원클릭 무중단 자동 교체 엔진
├── publish.ps1             # 버전 자동 증가, 빌드, Git 커밋/태그, Gitea 릴리즈 자동 배포 스크립트
├── build/                  # Windows 실행 파일 빌드 자산 (아이콘, 매니페스트)
├── frontend/               # 웹 프론트엔드 소스코드 (HTML, JS, Tailwind CSS v4)
├── server/                 # 중앙 프록시 서버 소스코드 (Go Gin 프레임워크)
└── server-data/            # 중앙 서버와 동기화되는 버전/고교데이터/배포 바이너리 저장소
```

## 💻 개발 및 빌드 방법

### 1. 개발 환경 준비
- [Go 1.23+](https://go.dev/)
- [Node.js 18+](https://nodejs.org/)
- [Wails CLI v2](https://wails.io/): `go install github.com/wailsapp/wails/v2/cmd/wails@latest`

### 2. 개발 모드 실행 (핫 리로드)
```bash
wails dev
```

### 3. 수동 빌드
```bash
wails build
# 빌드 결과물: build/bin/PHGC.exe
```

### 4. 자동 버전업 & 원클릭 중앙 배포
PowerShell 환경에서 제공되는 배포 스크립트를 사용하면 버전 번호 자동 증가, Wails 빌드, Git 커밋/태그, Gitea Release 및 `PHGC.exe` Asset 업로드를 수행합니다. 기획 문서는 저장소에서만 관리되며 Release Asset에는 포함하지 않습니다:

```powershell
.\publish.ps1 -Notes "배포할 업데이트 주요 내용을 입력합니다"
```
