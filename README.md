# 그래서? 넌 어디 갈래? (PHGC)

**울산 관내 중학교 3학년 고입 모의지원 및 1:1 맞춤형 진학상담 소프트웨어**

> 본 프로그램은 외부 클라우드나 외부 서버로 학생 개인정보를 단 1바이트도 전송하지 않는 **100% 오프라인 독립형(Standalone) 데스크톱 프로그램**입니다. 나이스(NEIS) 원본 엑셀 자료를 로컬 PC 내부에서 안전하게 분석하고, 고교별 맞춤 산출 엔진과 최근 5개년 합격선 데이터를 바탕으로 학생의 합격 가능성을 즉시 진단합니다.

---

## 🔒 100% 오프라인 보안 및 암호화 아키텍처

- **외부 전송 원천 차단**: 서버 통신 및 외부 네트워크 요청이 전혀 없는 독립 폐쇄망 구조로 설계되어 개인정보 유출을 원천적으로 차단합니다.
- **AES-256-GCM 로컬 강력 암호화**: 학교별로 설정한 [공용 데이터 암호]를 기반으로 군사 표준 수준의 AES-256-GCM 알고리즘을 적용하여 학급 배포 파일(`.phgcpkg`) 및 담임 취합 파일(`.phgcpatch`), 타교 교환 자료(`.phgcdata`)를 안전하게 보호합니다.
- **실행 경로 독립성 보장**: 프로그램 바로가기나 상대경로 실행 시에도 오류가 발생하지 않도록 `os.Executable()`을 통해 실행 파일(`.exe`)의 절대 경로를 기준으로 DB와 에셋을 안정적으로 자동 생성·관리합니다.
- **한글 및 공백 경로 완벽 지원**: 학교 현장의 한글 폴더명 및 공백이 포함된 파일 경로(예: `C:\2027학년도 3학년 진학상담\`)에서도 문제없이 구동되도록 UTF-8 경로 결합을 처리합니다.

## 📋 핵심 주요 기능 (v1.5.0)

1. **나이스(NEIS) 엑셀 자동 연동 & 전교 석차 스냅샷 동기화**:
   - 교과성적·출결·봉사활동 엑셀 3종 원클릭 파싱으로 학급별/학생별 통합 데이터베이스 자동 구축.
   - 주민등록번호 뒷자리 등 민감 정보는 메모리 적재 단계에서 즉시 마스킹 및 제외.
   - 학년부장 배포 패키지 생성 시 **전교 석차 스냅샷 자동 동기화**를 통해 담임교사 PC에서도 학년부장 화면과 100% 동일한 전교 백분율 및 일반고 합격 예측 산출.

2. **1:1 프라이버시 상담 모드 & 스마트 대시보드**:
   - **🔒 1:1 프라이버시 상담 모드**: 학생 번호(예: 1, 15) 또는 이름 검색 시 해당 학생만 단독 필터링되어, 학부모나 학생 대면 상담 중 타 학생의 점수와 지망이 전혀 노출되지 않는 안심 상담 환경 제공.
   - **다차원 실시간 정렬**: 번호순, 성명 가나다순, 일반계고 안정순/위험순, 마이스터고 유망순 등 원클릭 다각도 정렬 지원.
   - **대시보드 희망학교 원클릭 즉시 삭제([✕])**: 모달창을 열지 않고도 대시보드 목록의 배지 옆 `[✕]` 버튼으로 지망 학교를 즉시 취소·삭제.

3. **고교별·전형별 1차 맞춤형 성적 산출 및 심층 상담 엔진**:
   - **후기 일반계고**: 울산 내신 200점 만점 및 학년별/영역별 석차백분율(%) 정밀 산출.
   - **마이스터고**: 울산마이스터고(/300), 울산에너지고(/230), 현대공업고(/200) 전형별 가중치 자동 계산.
   - **특성화고**: 관내 특성화고 일반전형 및 취업희망자 특별전형 1차 점수(/100) 실시간 산출.
   - **학과 지망 중복 방지 실시간 비활성화**: 1~5지망 입력 시 이미 선택한 학과는 타 지망에서 자동으로 비활성화(회색) 처리되어 중복 접수 오류 원천 차단.
   - **다각도 입결 비교**: [🎯 직전 1개년], [📊 최근 3년 평균], [📈 최근 5년 평균] 탭 및 공식 최고점·평균점·최저점 3대 합격선 동시 대조.

4. **교내 안전 분할 배포 및 취합 워크플로우 (이력 보존 & 비밀번호 복구)**:
   - **상담 이력 100% 자동 보존**: 학기 중 학년부장 배포 패키지(`.phgcpkg`)를 재가져오기 하더라도 기존에 담임이 입력해 둔 상담일지, 학생별 1~5지망, 메모가 안전하게 자동 병합·보존.
   - **비밀번호 재설정 파일(`.phgcreset`) 복구**: 담임교사가 비밀번호를 분실했을 경우 학년부장이 발급한 암호화 재설정 파일로 안전하게 자가 복구 지원.
   - **다중 취합 파일(`.phgcpatch`) 1초 일괄 병합**: 학년부장은 전 학급 패치를 다중 선택하여 1초 만에 검증 및 최종 본교 DB에 일괄 반영.

5. **학교 원서대장 및 지원현황 통계 (A4 공식 양식)**:
   - 대한민국 학교 공식 한글(HWP) 서식의 A4 원서대장 자동 생성 및 학생 수에 맞춘 1페이지 자동 레이아웃.
   - 동적 결재라인 설정(담임, 학년부장, 교무부장, 진로부장, 교감, 교장) 및 반별 자동 분할 인쇄 지원.
   - 후기 일반고 배정고 인라인 즉시 입력 및 특성화고 추가모집 자동 표기.

6. **프리미엄 글래스모피즘 모달 시스템**:
   - 브라우저 기본 시스템 팝업을 전면 배제하고, 통일된 고급 모달 인터페이스를 통해 안전하고 미려한 사용자 경험 제공.

## 🚀 빌드 및 실행 방법

### 개발 환경 실행
```powershell
wails dev
```

### 배포용 단일 실행 파일(.exe) 빌드
```powershell
wails build
```
빌드 완료 시 `build/bin/PHGC.exe`가 생성됩니다.

### 버전 릴리즈 배포
```powershell
# GitHub 릴리즈 배포 파이프라인 (자동 빌드, Git 커밋, 태깅, GitHub Releases 바이너리 업로드)
.\publish.ps1 -Notes "최신 기능 업데이트 및 버그 수정" -Version "1.2.1"
```
