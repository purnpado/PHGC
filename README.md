# PHGC — 고입 진학상담·합격 예측 프로그램

울산 관내 중학교의 3학년 진학지도를 위한 독립형 Windows 프로그램입니다. 나이스 자료를 교내에서 처리하고, 학생별 일반계고·마이스터고·특성화고의 **1차 전형 기준**을 비교합니다.

## 운영 구조

- **PHGC 저장소(비공개)**: 데스크톱 프로그램 소스, 전형 산출식, `server-data` 기준 데이터
- **EduBridge-Server(별도 저장소/배포)**: 업데이트·공지·피드백·공개 커트라인 중계 서버
- **Gitea Release Asset**: 자동업데이트용 `PHGC.exe`만 업로드

중계 서버의 소스·Docker 설정·토큰은 PHGC 저장소에 두지 않습니다. 운영 환경변수는 `EduBridge-Server/.env`에만 두고, 저장소에는 각 프로젝트의 `.env.example`만 관리합니다.

## 사용자 흐름

1. 학년부장이 프로그램을 처음 실행해 입학년도·학급 수·공용 데이터 암호를 설정합니다.
2. 나이스 성적·출결·봉사 자료를 불러오고, 학교별 커트라인을 확인·입력합니다.
3. [사용자 및 권한 관리]에서 각 학급별 암호화 배포 자료(`.phgcpkg`)를 생성하여 담임교사에게 전달합니다.
4. 담임교사는 로그인 화면의 [배포 자료 가져오기]를 통해 전달받은 파일을 적용하고, 공용 데이터 암호와 초기 비밀번호로 처음 접속한 후 개인 비밀번호로 변경하여 사용합니다.
5. 담임교사는 [취합자료 제출]을 통해 자기 반 변경분(`.phgcpatch`)을 내보내 학년부장에게 전달하고, 학년부장은 [취합자료 병합] 화면에서 학생별 항목을 확인·선택하여 병합합니다.

학생 DB 및 변경분 파일은 공용 데이터 암호 기반 AES-256-GCM 방식으로 강력히 암호화되어 안전하게 관리됩니다.

## 주요 기능

- **나이스 자료 연동**: 성적·출결·봉사 자료의 자동 파싱 및 학급별 암호화 처리
- **고교별 맞춤 성적 산출**:
  - 후기 일반계고 내신 200점 만점 및 석차백분율(%) 산출
  - 마이스터고(울산마이스터고, 울산에너지고, 현대공업고) 일반/특별전형 1차 전형 점수 산출
  - 관내 특성화고 일반전형 및 취업자 특별전형 1차 전형 점수 산출
  - 자사고·외고 및 전기 기타고(울산예술고, 울산스포츠과학고, 울산고운고, 애니원고, 과학고 등) 지원 이력 및 메모 관리
- **고교별·학과별 커트라인 통합 관리**: 입학년도별 자동 전환, 전형별 최저합격선 및 최고불합격선 집중 관리, 고교 공식 공개 합격선 데이터 중앙 서버 연동 및 실시간 고교 검색
- **미진학(진학포기) 학생 관리**: 미진학 선택 시 지원 상태 자동 동기화 및 사유(취업·가사, 해외유학, 검정고시 등) 분리 관리
- **학교 내부 원서대장 및 지원현황 통계**: 전교생/학급별 원서접수 대장, 입시 결과 확정 및 커트라인 반영, 반응형 모달 및 키보드(ESC) 편의 기능 지원
- **안전한 교내 자료 취합/배포**: 담임 취합자료(`.phgcpatch`) 선택 병합 및 학급별 배포자료(`.phgcpkg`) 생성
- **EduBridge 연동**: 안전한 자동 업데이트 및 공지 사항 확인, 커트라인 및 공식 입결 크라우드소싱 연계

면접·신체검사·취업희망서처럼 공개 산출 기준이 아닌 요소는 합격 예측 점수에 포함하지 않습니다.

## 저장소 구조

```text
PHGC/
├── app.go, db.go, crypto_store.go    # 앱·암호화 데이터 계층
├── calc.go, calc_school.go           # 일반계고·학교별 1차 전형 산출식
├── parser*.go                        # 나이스 자료 파서
├── sync.go, updater.go               # EduBridge 연동 및 자동업데이트
├── frontend/                         # Wails/Vite 사용자 화면
├── server-data/                      # 버전·고교/학과·커트라인 기준 데이터
├── docs/                             # 기획·전형요강 분석 문서
└── publish.ps1                       # 릴리즈 자동화 스크립트
```

## 개발 및 릴리즈

```powershell
# 개발 실행
wails dev

# 빌드
wails build

# 버전 증가 · 빌드 · 커밋 · 태그 · Gitea Release EXE 업로드
.\publish.ps1 -Notes "업데이트 내용"
```

릴리즈 전에 실제 학생 몇 명의 1차 산출 결과를 해당 고교 전형요강 또는 학교 제공 계산표와 대조해야 합니다.

## 보안 원칙

- `.env`, API 토큰, 비밀번호, DB, 나이스 원본 파일은 Git에 올리지 않습니다.
- 중앙 서버로 보내는 커트라인은 중학교명·입학년도·고교명·학과/학교전체·전형·커트라인 점수만 허용합니다.
- 학생·학급·교사 식별 정보는 중앙 서버 전송 대상이 아닙니다.
