# PHGC (고입 내신 산출 및 합격 예측 프로그램)

울산 관내 중학교의 고등학교 입시를 위한 내신 산출 및 합격 예측을 돕는 단독 실행 프로그램입니다.
관리자(학년부장)와 담임 모드를 지원하며, 로컬 환경에서 성취평가제 기반 성적 데이터를 쾌적하게 관리할 수 있도록 설계되었습니다.

## 주요 기능

- **관리자 모드 (학년부장용)**
  - 나이스(NEIS) 엑셀 성적 파일 Import 및 반별 DB 분할 저장
  - 고교별 합격 커트라인 점수 관리 및 동기화 (특성화고/마이스터고 학과 정보 포함)
  - 초기 설정 및 비밀번호를 통한 인증 관리

- **담임 모드 (담임교사용)**
  - 담당 학급의 성적 DB(.db) 단독 로드
  - 학생별 내신 성적 산출 및 시각적 게이지/차트 UI 제공
  - 고교 커트라인 대비 학생별 합격 가능성 예측

## 기술 스택

- **프론트엔드:** HTML, Vanilla JS, Tailwind CSS v4 (SPA 방식 글래스모피즘 UI)
- **백엔드:** Go 언어 + Wails v2 프레임워크
- **데이터베이스:** 순수 Go 구현 SQLite (`modernc.org/sqlite`)
- **버전 관리 및 서버 연동:** Gitea REST API 연동

## 빌드 및 실행 방법

이 프로젝트는 Wails 프레임워크를 사용합니다. Wails 환경이 설정되어 있어야 합니다.

```bash
# 개발 모드로 실행 (핫 리로드 지원)
wails dev

# 배포용 실행 파일(.exe) 빌드
wails build
```

빌드가 완료되면 `build/bin/` 폴더에 `PHGC.exe` 파일이 생성됩니다.

## 디렉토리 구조 설명

- `main.go`, `app.go`, `sync.go`: Go 백엔드 로직 (API 바인딩, Gitea 연동)
- `db.go`: SQLite 기반 설정 및 데이터베이스 관리
- `frontend/`: 웹 기반 UI 에셋 (HTML/CSS/JS)
- `server-data/`: Gitea 서버와 동기화되는 원격 데이터 저장소 
- `data/`: 로컬 프로그램 실행 시 생성되는 DB 및 동기화된 파일 저장소 (gitignore됨)
